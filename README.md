# RPG 英雄小队管理系统

一个基于 C# 控制台的 RPG 英雄管理系统，用于管理英雄小队、装备背包，并支持数据持久化存档。

---

## 项目简介

这是一个面向对象编程的练习项目，实现了英雄的创建、装备管理、背包排序、数据存档与读档等核心功能。项目采用了抽象类、继承、多态、泛型集合、JSON 序列化等 C# 核心技术。


## 功能列表

- 查看所有英雄信息，包括职业、等级、属性、技能和装备背包
- 给指定英雄添加装备，可自定义名称、攻击力、血量和类型
- 按攻击力排序英雄背包，使用冒泡排序降序排列
- 查找全队最强攻击装备
- 删除指定装备，删除后自动补位
- 数据持久化，使用 JSON 存档和读档
- 支持三种职业：战士、法师、刺客
- 输入校验与异常处理


## 技术栈

- C# 核心编程语言
- .NET 6 / .NET 8 运行环境（基于控制台应用）
- System.Text.Json（JSON 序列化与反序列化，含多态支持）
- List<T>（动态集合管理）
- 面向对象（抽象类、继承、多态、封装）


## 如何使用

### 运行程序

1. 使用 Visual Studio 2022 打开项目
2. 按 `F5` 启动程序
3. 首次运行会自动创建默认英雄：剑圣·战士 / 阿狸·法师 / 劫·刺客

### 主菜单

```
======= RPG 英雄小队管理系统 =======
1. 查看所有英雄信息
2. 给指定英雄添加装备
3. 按攻击力排序英雄背包
4. 查找全队最强攻击装备
5. 删除指定装备
6. 退出系统
====================================
请输入选项（1-6）：
```

### 交互示例

- **添加装备**：选择英雄编号 → 输入装备名称、攻击力、血量、类型（1-武器，2-护甲，3-饰品）
- **排序背包**：选择英雄编号 → 背包内装备按攻击力降序排列，每轮排序实时输出
- **查找最强**：自动遍历全队所有英雄的背包，输出攻击力最高的装备


## 存档机制

- 数据保存在 `save.json` 文件中，自动生成于程序运行目录
- 支持多态序列化（父类引用指向子类对象，JSON 自动识别类型）
- 加载失败时会自动创建默认英雄，保证程序不崩溃


## 面向对象设计

### 类结构图

```
abstract class Hero
    ├── class Warrior : Hero
    │   ├── 耐力（Stamina）
    │   └── 技能：猛击
    ├── class Mage : Hero
    │   ├── 法力（Mana）
    │   └── 技能：魔法
    └── class Assassin : Hero
        ├── 敏捷（Agility）
        └── 技能：背刺
```

### 关键抽象方法

- `GetSkillDescription()`：子类必须实现，返回技能描述
- `ShowInfo()`：虚方法，子类可重写扩展显示内容
